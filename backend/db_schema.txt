# Optimized for AI SQL Query Generation with Institution-Based Filtering

## CORE PRINCIPLE: INSTITUTION-BASED DATA ISOLATION
Every query MUST filter by institution_id either directly or through relationships.
All data belongs to an institution and must be properly scoped.

## SAMPLE QUERIES BY COMMON USE CASES

### 1. GET ALL EMPLOYEES FOR AN INSTITUTION
```sql
SELECT e.*, u.fullname, u.email, d.name as department_name, b.branch_name
FROM employee_employee e
JOIN users_customuser u ON e.user_id = u.id
JOIN institution_department d ON e.department_id = d.id
JOIN institution_branch b ON e.payroll_branch_id = b.id
WHERE d.institution_id = ? AND e.is_active = true AND e.deleted_at IS NULL;
